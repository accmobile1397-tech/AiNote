# Canonical Knowledge Map
## Version 3.1

This map records the current canonical relationship between the personal Knowledge Laboratory and the executable Agentic SDLC Bootstrap.

## Knowledge Source

`AiNote` is the upstream Knowledge Laboratory. It contains discoveries, patterns, preferences, experiments, project learning and canonical reusable knowledge.

## Executable Baseline

`Agentic-SDLC-Project-Bootstrap` is the curated, versioned, executable mirror of approved and generalized knowledge needed to initialize and operate new projects.

## Project Feedback Loop

```text
AiNote
→ Review / Generalize
→ Bootstrap
→ Project
→ Learning
→ AiNote
→ Review / Generalize
→ Bootstrap (next version)
```

## Promotion Rule

Project learning is first captured in AiNote. Only reviewed and generalized knowledge may influence Bootstrap.

## Version Rule

Bootstrap is versioned and project instances retain the Bootstrap version they were initialized from unless they explicitly migrate.
