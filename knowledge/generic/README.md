# Generic / Shared Knowledge

Knowledge in this area is not owned by a single site/product and is intended to be reusable across multiple projects.

Examples may include common authentication, UX, accessibility, infrastructure, product, or engineering patterns.

Every item should preserve provenance: source, date/context where useful, and the reasoning that supports generalization.

If a finding is actually specific to one of our own sites/products, place it in that site's knowledge space instead.
