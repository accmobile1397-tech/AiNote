# AIMentor

Own product/site knowledge space for AIMentor.

Keep AIMentor-related observations, research, candidates, validated knowledge, and product decisions discoverable under this context. This does not mean every finding is approved or implemented.

AI-native career mentoring / development context associated with the career ecosystem.

## Knowledge lifecycle

`observations → candidates → knowledge → decisions`

Promotion requires the repository governance/review process. Project implementation remains owned by the AIMentor project repository when applicable.
