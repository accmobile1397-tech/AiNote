# Agent Entrypoint State Reconciliation Pattern v1.0

## Origin
Generalized from Bootstrap LC-0004.

## Canonical Principle
Absence of a dedicated artifact for the current milestone is NOT evidence that executable work is undefined or blocked. Before declaring a milestone undefined, an Agent MUST reconcile the canonical entrypoint, machine-readable state, workflow, approvals, roadmap, active protocols/skills, and milestone artifacts.

## Reusable Value
This pattern enables durable fresh-agent continuation from repository state instead of chat history, assumptions, or artifact-name discovery alone.

## Boundary
The reconciliation rule is reusable. Exact entrypoint documents, state schema, roadmap format, and artifact paths are project-specific.

## Promotion Status
Canonical generalized knowledge in AiNote. Bootstrap impact requires a separate governed promotion decision.
