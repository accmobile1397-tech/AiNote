# Knowledge Loop Durable Capture and Intake Pattern v1.0

## Origin
Generalized from Bootstrap LC-0001.

## Canonical Principle
Project discoveries and reusable learning MUST be durably captured and routed through the governed Knowledge Loop. The loop MUST NOT depend on conversation memory or an explicit human reminder to preserve the discovery.

## Required Lifecycle
Project learning → durable candidate capture → AiNote intake → review/generalization → governed Bootstrap promotion.

## Boundary
This pattern defines the governance invariant, not a repository-specific implementation. Concrete triggers, file paths, validators, and automation remain project-specific.

## Promotion Status
Canonical generalized knowledge in AiNote. No direct Bootstrap mutation is implied by this document.
